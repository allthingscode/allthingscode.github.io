Privacy Policy

Effective and last updated: September 19, 2026

Scope

This policy applies to allthingscode Workspace CLI, a private, non-commercial Google OAuth integration used only by its owner. The integration is not offered to the public and does not accept accounts belonging to other users.

Google user data accessed

At the owner's direction, the integration may access the owner's Google Tasks, Calendar, Drive, Gmail, Docs, Sheets, and Slides data. Depending on the requested operation, this can include task records, calendar events, file metadata and content, email messages and settings, documents, spreadsheets, and presentations.

How data is used

Google user data is used only to carry out actions explicitly requested by the owner, such as finding information, creating or updating an item, or preparing a requested summary. The OAuth client itself does not use Google user data for advertising, user profiling, resale, or unrelated purposes.

Storage and retention

OAuth credentials are stored on the owner's Windows computer using encrypted operating-system credential storage. The integration does not maintain a separate hosted database of Google user data. Command results may be processed transiently on the local machine and, when the owner explicitly invokes an AI-assisted workflow, by the AI service selected for that session. Any local files, Google Workspace changes, or conversation history created at the owner's request are retained according to the owner's actions and the applicable service settings.

Sharing and disclosure

The integration does not sell Google user data or share it with data brokers, advertisers, or unrelated third parties. Data is transmitted to Google APIs and may be sent to an AI-service provider only when the owner intentionally uses that provider to perform the requested workflow. Use by an AI-service provider is governed by the owner's account settings and that provider's terms and privacy policy. OAuth refresh tokens and client secrets are not intentionally included in AI prompts or command output.

Security

The integration uses Google's OAuth authorization flow and encrypted local credential storage. Access is limited to the owner's account. The owner controls the computer, the OAuth client, and any AI services used with the integration.

Revoking access and deleting data

The owner can revoke the integration's access at any time from the Google Account connections page and can remove the locally encrypted credentials from the computer. Google Workspace data created or changed through the integration can be managed directly in the relevant Google app.

Google API Services User Data Policy

The integration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

This policy will be updated if the integration's data access or handling practices materially change. The effective date above identifies the current version.
