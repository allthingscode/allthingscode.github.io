Personal integration

allthingscode Workspace CLI

allthingscode Workspace CLI is a private, non-commercial integration used by its owner to work with the owner's own Google Workspace data through local command-line automation and explicitly invoked AI-assisted workflows.

What it does

The integration connects to Google Tasks, Calendar, Drive, Gmail, Docs, Sheets, and Slides. It reads or changes data only when the owner requests an action. It is not offered as a service to the public and does not have other users.

Data handling

OAuth credentials are stored locally using encrypted operating-system credential storage. The integration does not operate a separate data-collection backend, sell Google user data, or use it for advertising. See the Privacy Policy for details about access, processing, retention, sharing, security, and revocation.
